# 文件与附件及数据字典接口规范

## 一、系统字典相关接口

### 1. SysDict 控制器
**控制器类**: `SysDictController`
**包路径**: `com.simbest.cloud.cores.sys.web`
**主要功能**: 提供数据字典类型的管理功能，包括字典类型的增删改查等操作

主要接口:
1. `POST /sys/dict/create`
   - 功能：新增一个字典类型
   - 参数：`sysDict`: 字典类型对象
   - 返回值：JsonResponse，包含新增的字典类型信息

2. `POST /sys/dict/update`
   - 功能：修改一个字典类型
   - 参数：`sysDict`: 字典类型对象
   - 返回值：JsonResponse，包含修改后的字典类型信息

3. `POST /sys/dict/deleteById`
   - 功能：根据ID删除字典类型
   - 参数：`id`: 字典类型ID
   - 返回值：JsonResponse，表示操作结果

4. `POST /sys/dict/delete`
   - 功能：先修改再逻辑删除字典类型
   - 参数：`sysDict`: 字典类型对象
   - 返回值：JsonResponse，表示操作结果

5. `POST /sys/dict/deleteAllByIds`
   - 功能：批量逻辑删除字典类型
   - 参数：`ids`: 字典类型ID数组
   - 返回值：JsonResponse，表示操作结果

6. `POST /sys/dict/updateEnable`
   - 功能：修改字典类型的可见状态
   - 参数：
     - `id`: 字典类型ID
     - `enabled`: 是否可见
   - 返回值：JsonResponse，包含修改后的字典类型信息

7. `POST /sys/dict/findAll`
   - 功能：获取字典类型信息列表并分页
   - 参数：
     - `page`: 页码
     - `size`: 每页大小
     - `direction`: 排序方向
     - `properties`: 排序属性
     - `sysDict`: 查询条件
   - 返回值：JsonResponse，包含分页的字典类型列表

8. `POST /sys/dict/findDictTree`
   - 功能：获取字典树（不分页）
   - 参数：无
   - 返回值：JsonResponse，包含字典树结构

9. `POST /sys/dict/createChild`
   - 功能：新增下级字典类型
   - 参数：`dict`: 字典类型对象
   - 返回值：JsonResponse，表示操作结果

10. `POST /sys/dict/listJson`
    - 功能：获取JSON格式的数据字典
    - 参数：无
    - 返回值：JsonResponse，包含启用的字典类型列表

2. `POST /sys/dictValue/update`

3. `POST /sys/dictValue/deleteById`
   - 功能：根据ID删除字典值

4. `POST /sys/dictValue/delete`
   - 功能：先修改再逻辑删除字典值
   - 参数：`sysDictValue`: 字典值对象
   - 返回值：JsonResponse，表示操作结果

5. `POST /sys/dictValue/deleteAllByIds`
   - 功能：批量逻辑删除字典值
   - 参数：`ids`: 字典值ID数组
   - 返回值：JsonResponse，表示操作结果

6. `POST /sys/dictValue/updateEnable`
   - 功能：修改字典值的可见状态
   - 参数：
     - `id`: 字典值ID
     - `enabled`: 是否可见
   - 返回值：JsonResponse，包含修改后的字典值信息

7. `POST /sys/dictValue/findById`
   - 功能：根据ID查询字典值
   - 参数：`id`: 字典值ID
   - 返回值：JsonResponse，包含字典值信息

8. `POST /sys/dictValue/findAll`
   - 功能：获取字典值信息列表并分页
   - 参数：
     - `page`: 页码
     - `size`: 每页大小
     - `direction`: 排序方向
     - `properties`: 排序属性
     - `sysDictValue`: 查询条件
   - 返回值：JsonResponse，包含分页的字典值列表

9. `POST /sys/dictValue/createChild`
   - 功能：新增子字典值
   - 参数：`dictValue`: 字典值对象
   - 返回值：JsonResponse，表示操作结果

10. `POST /sys/dictValue/findDictValue`
    - 功能：根据字典值对象查询满足条件的数据字典值
    - 参数：`sysDictValue`: 查询条件
    - 返回值：JsonResponse，包含查询结果

11. `POST /sys/dictValue/findByDictTypeAndName`
    - 功能：根据字典类型和字典值名称获取字典值
    - 参数：
      - `dictType`: 字典类型
      - `name`: 字典值名称
    - 返回值：JsonResponse，包含查询结果

12. `POST /sys/dictValue/findByDictTypeAndNameAndBlocidAndCorpid`
    - 功能：根据字典类型、字典值名称、集团Id和企业Id获取字典值
    - 参数：
      - `dictType`: 字典类型
      - `name`: 字典值名称
      - `blocid`: 集团ID
      - `corpid`: 企业ID
    - 返回值：JsonResponse，包含查询结果

13. `POST /sys/dictValue/findAllDictValue`
    - 功能：查看数据字典的所有值
    - 参数：无
    - 返回值：JsonResponse，包含所有字典值

14. `POST /sys/dictValue/findAllDictValueMapList`
    - 功能：查看数据字典的所有值（Map结构）
    - 参数：无
    - 返回值：JsonResponse，包含字典值Map（key为dictType，value为字典值list）

15. `POST /sys/dictValue/findDictValueMapList`
    - 功能：查看指定数据字典类型的字典值（Map结构）
    - 参数：`typeList`: 字典类型数组
    - 返回值：JsonResponse，包含字典值Map（key为dictType，value为字典值list）

## 二、系统文件相关接口

### 1. SysFile 控制器
**控制器类**: `SysFileController`
**包路径**: `com.simbest.cloud.cores.sys.web`
**主要功能**: 提供文件上传、下载、预览等功能，支持传统方式和REST方式

主要接口:
1. `POST /sys/file/uploadFile`
   - 功能：上传单个文件
   - 参数：
     - `file`: 上传的文件
     - `pmInsType`: 流程实例类型
     - `pmInsId`: 流程实例ID
     - `pmInsTypePart`: 流程实例类型部分
   - 返回值：JsonResponse，包含上传结果

2. `POST /sys/file/updateFile`
   - 功能：更新文件
   - 参数：
     - `file`: 上传的文件
     - `pmInsId`: 流程实例ID
     - `id`: 文件ID
   - 返回值：JsonResponse，包含更新结果

3. `POST /sys/file/getFilesByPmInsId`
   - 功能：根据流程实例ID获取文件列表
   - 参数：
     - `pmInsId`: 流程实例ID
     - `appCode`: 应用代码
   - 返回值：JsonResponse，包含文件列表

4. `POST /sys/file/getFilesByProcessInsId`
   - 功能：根据流程实例ID获取文件列表
   - 参数：
     - `processInsId`: 流程实例ID
     - `appCode`: 应用代码
   - 返回值：JsonResponse，包含文件列表

5. `POST /sys/file/uploadProcessFiles`
   - 功能：传统方式上传附件（支持IE8）
   - 参数：
     - `request`: HTTP请求对象
     - `response`: HTTP响应对象
   - 返回值：void
   - 功能描述：支持关联流程，会保存到数据库SYS_FILE

6. `POST /sys/file/uploadProcessFiles/rest`
   - 功能：REST方式上传附件
   - 参数：
     - `request`: HTTP请求对象
     - `response`: HTTP响应对象
   - 返回值：ResponseEntity，包含上传结果
   - 功能描述：支持关联流程，会保存到数据库SYS_FILE

7. `POST /sys/file/uploadCompressImages2`
   - 功能：传统方式分辨率压缩图片（支持IE8）
   - 参数：
     - `request`: HTTP请求对象
     - `response`: HTTP响应对象
   - 返回值：void
   - 功能描述：支持关联流程，会保存到数据库SYS_FILE

8. `POST /sys/file/uploadCompressImages2/rest`
   - 功能：REST方式分辨率压缩图片
   - 参数：
     - `request`: HTTP请求对象
     - `response`: HTTP响应对象
   - 返回值：ResponseEntity，包含上传结果
   - 功能描述：支持关联流程，会保存到数据库SYS_FILE

9. `GET /sys/file/downloadVideo`
   - 功能：下载视频文件
   - 参数：
     - `request`: HTTP请求对象
     - `response`: HTTP响应对象
     - `id`: 文件ID
   - 返回值：void

10. `GET /sys/file/download`
    - 功能：下载文件
    - 参数：
      - `request`: HTTP请求对象
      - `id`: 文件ID
    - 返回值：ResponseEntity，包含文件内容

11. `GET /sys/file/ngopen`
    - 功能：打开文件（新版本）
    - 参数：
      - `id`: 文件ID
      - `uploadPath`: 上传路径
    - 返回值：String，重定向URL

12. `GET /sys/file/open`
    - 功能：打开文件
    - 参数：`id`: 文件ID
    - 返回值：String，重定向URL

13. `GET/POST /sys/file/openurl`
    - 功能：打开URL
    - 参数：`url`: 要打开的URL
    - 返回值：String，重定向URL

14. `GET/POST /sys/file/get/url`
    - 功能：获取URL内容（不重定向）
    - 参数：`url`: 要获取的URL
    - 返回值：ResponseEntity，包含URL内容

15. `GET/POST /sys/file/getRedirectUrl`
    - 功能：获取Office Web 365重定向URL
    - 参数：`url`: 原始URL
    - 返回值：ResponseEntity，包含重定向URL

16. `POST /sys/file/deleteById`
    - 功能：删除文件
    - 参数：`id`: 文件ID
    - 返回值：JsonResponse，表示操作结果

17. `POST /sys/file/deleteByIdNoFile`
    - 功能：删除文件记录（不删除实际文件）
    - 参数：`id`: 文件ID
    - 返回值：JsonResponse，表示操作结果

18. `POST /sys/file/update`
    - 功能：更新文件信息
    - 参数：`sysFile`: 文件对象
    - 返回值：JsonResponse，表示操作结果

19. `GET/POST /sys/file/scanCheckRealFile`
    - 功能：扫描检查实际文件
    - 参数：
      - `id`: 文件ID
      - `isLocal`: 是否本地文件
    - 返回值：JsonResponse，表示操作结果

20. `GET /sys/file/downloadZip`
    - 功能：下载ZIP文件
    - 参数：
      - `request`: HTTP请求对象
      - `ids`: 文件ID列表（逗号分隔）
    - 返回值：ResponseEntity，包含ZIP文件内容

## 三、继承关系说明

1. 所有Controller都继承自`LogicController`
2. `LogicController`继承自`GenericController`
3. 所有Controller都支持SSO和API双重访问方式

## 四、注意事项

1. 字典相关接口支持公共字典和私有字典的管理
2. 文件相关接口支持多种存储方式（本地、FTP、SFTP等）
3. 所有接口都支持SSO和API双重访问方式
4. 缓存工具类使用Redis实现，支持多级缓存策略
