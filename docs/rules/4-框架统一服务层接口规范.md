# 服务层接口文档

## IGenericService 接口文档

### 接口描述
基础实体通用服务层接口，提供基础的 CRUD 操作、分页查询、条件查询等功能。

### 包路径
com.simbest.cloud.cores.base.service

### 泛型说明
- T：实体类型，需继承 GenericModel
- PK：主键类型，需实现 Serializable

### 方法列表

#### 分页相关方法
- **Pageable getPageable()**
  - 入参：无
  - 出参：Pageable
  - 功能描述：获取默认分页对象

- **Pageable getPageable(int page, int size)**
  - 入参：page（页码），size（每页条数）
  - 出参：Pageable
  - 功能描述：根据页码和每页条数获取分页对象

- **Pageable getPageable(int page, int size, String direction, String properties)**
  - 入参：page（页码），size（每页条数），direction（排序方向），properties（排序属性）
  - 出参：Pageable
  - 功能描述：根据排序规则和属性获取分页对象

#### 条件查询相关方法
- **Specification<T> getSpecification(T entity)**
  - 入参：entity（实体对象）
  - 出参：Specification<T>
  - 功能描述：根据实体对象生成查询条件

- **Specification<T> getSpecification(Map<String, Object> conditions)**
  - 入参：conditions（条件集合）
  - 出参：Specification<T>
  - 功能描述：根据 Map 条件生成查询条件

- **Specification<T> getSpecification(Condition condition)**
  - 入参：condition（复杂条件对象）
  - 出参：Specification<T>
  - 功能描述：根据复杂条件对象生成查询条件

#### 统计相关方法
- **long count()**
  - 入参：无
  - 出参：long
  - 功能描述：统计所有记录数

- **long count(Specification<T> specification)**
  - 入参：specification（条件对象）
  - 出参：long
  - 功能描述：根据条件统计记录数

#### 查询相关方法
- **boolean exists(PK id)**
  - 入参：id（主键）
  - 出参：boolean

  - 出参：T

- **T findById(PK id)**
  - 入参：id（主键）
  - 出参：T

  - 功能描述：查询全部记录（分页）

- **Page<T> findAll(Pageable pageable)**
  - 入参：pageable（分页对象）
  - 出参：Page<T>

- **Page<T> findAll(Sort sort)**

- **Iterable<T> findAllNoPage()**

- **Iterable<T> findAllNoPage(Sort sort)**
  - 入参：sort（排序对象）
  - 出参：Iterable<T>
  - 功能描述：根据排序字段查询全部记录（不分页）

- **Iterable<T> findAllByIDs(Iterable<PK> ids)**
  - 入参：ids（主键集合）
  - 出参：Iterable<T>

- **Page<T> findAll(Specification<T> conditions, Pageable pageable)**

## ILogicService 接口文档

### 接口描述
业务实体通用服务层接口，涉及业务实体的所有操作需要记录创建人信息和更新人信息。继承自 ISystemService 接口，提供逻辑删除等业务实体特有的功能。

### 包路径
com.simbest.cloud.cores.base.service

### 泛型说明
- T：实体类型，需继承 LogicModel
- PK：主键类型，需实现 Serializable

### 方法列表

#### 状态更新方法
- **T updateEnable(PK id, boolean enabled)**
  - 入参：id（主键），enabled（是否可用）
  - 出参：T
  - 功能描述：根据主键 ID 更新实体的可用状态

#### 定时删除方法
- **void scheduleLogicDelete(PK id, LocalDateTime localDateTime)**
  - 入参：id（主键），localDateTime（计划删除时间）
  - 出参：void
  - 功能描述：根据设定时间，定时删除指定 ID 的实体

- **void scheduleLogicDelete(T entity, LocalDateTime localDateTime)**
  - 入参：entity（实体对象），localDateTime（计划删除时间）
  - 出参：void
  - 功能描述：根据设定时间，定时删除指定实体

#### 更新方法
- **T updateWithNull(T o)**
  - 入参：o（待更新实体）
  - 出参：T
  - 功能描述：修改实体，允许实体主键字段无值

#### 查询方法
- **List<T> findAllNoPage()**
  - 入参：无
  - 出参：List<T>
  - 功能描述：查询所有未删除的记录（不分页）

- **List<T> findAllNoPage(Sort sort)**
  - 入参：sort（排序对象）
  - 出参：List<T>
  - 功能描述：根据排序规则查询所有未删除的记录（不分页）

- **List<T> findAllByIDs(Iterable<PK> ids)**
  - 入参：ids（主键集合）
  - 出参：List<T>
  - 功能描述：根据主键集合查询未删除的记录

- **List<T> findAllNoPage(Specification<T> conditions)**
  - 入参：conditions（条件对象）
  - 出参：List<T>
  - 功能描述：根据条件查询未删除的记录（不分页）

- **List<T> findAllNoPage(Specification<T> conditions, Sort sort)**
  - 入参：conditions（条件对象），sort（排序对象）
  - 出参：List<T>
  - 功能描述：根据条件和排序规则查询未删除的记录（不分页）

## GenericService 类文档

com.simbest.cloud.cores.base.service.impl

- @Slf4j：提供日志功能

- T：实体类型，需继承 GenericModel
