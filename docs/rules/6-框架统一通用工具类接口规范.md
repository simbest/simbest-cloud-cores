## ApplicationContextProvider

### 类说明
`ApplicationContextProvider` 是一个Spring上下文工具类，用于在非Spring管理的类中获取Spring容器中的Bean。

### 方法列表

#### 1. getApplicationContext
```java
public static ApplicationContext getApplicationContext()
```
- **功能描述**：获取Spring应用上下文对象
- **返回值**：ApplicationContext - Spring应用上下文对象

#### 2. getActiveProfile
```java
public static String getActiveProfile()
```
- **功能描述**：获取当前激活的Spring配置文件
- **返回值**：String - 当前激活的配置文件名称

#### 3. getBean
```java
public static Object getBean(String name)
```
- **功能描述**：通过Bean名称获取Bean实例
- **参数**：
  - name: String - Bean的名称
- **返回值**：Object - Bean实例

#### 4. getBean
```java
public static <T> T getBean(Class<T> clazz)
```
- **功能描述**：通过Bean类型获取Bean实例
- **参数**：
  - clazz: Class<T> - Bean的类型
- **返回值**：T - 指定类型的Bean实例

#### 5. getBean
```java
public static <T> T getBean(String name, Class<T> clazz)
```
- **功能描述**：通过Bean名称和类型获取Bean实例
- **参数**：
  - name: String - Bean的名称
  - clazz: Class<T> - Bean的类型
- **返回值**：T - 指定类型的Bean实例

#### 6. getBeansOfType
```java

```
- **功能描述**：获取指定类型的所有Bean实例
- **参数**：
  - type: Class<T> - Bean的类型
- **返回值**：Map<String, T> - Bean名称到Bean实例的映射

#### 1. hasUrlEncoded

  规则：  
  - 0-9、a-z、A-Z、`+`、`-`、`_`、`.`、`*` 保留不变

- **参数**：
  - str: String - 待判断的字符串
- **返回值**：boolean - `true` 表示已编码，`false` 表示未编码
