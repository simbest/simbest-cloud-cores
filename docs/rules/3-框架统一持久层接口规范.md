### 2. BaseRepository

**基本信息**
- **包路径**: `com.simbest.cloud.cores.base.repository`
- **用途**: 基础Repository接口，提供通用的数据访问方法
- **作者**: baimengqi
- **创建时间**: 2017/12/26
- **修改时间**: 2018/01/04

**继承关系**
- 继承自 `JpaRepository<T, PK>` 和 `JpaSpecificationExecutor<T>`
  - 泛型参数1: `T` - 实体类型
  - 泛型参数2: `PK` - 主键类型，必须实现 Serializable 接口

**接口方法**

#### getPageable
```java
default Pageable getPageable()
```
- **功能**: 获取默认分页对象
- **返回值**: 
  - `Pageable`: 使用默认页码和每页条数的分页对象

#### getPageable(int page, int size)
```java
default Pageable getPageable(int page, int size)
```
- **功能**: 获取指定页码和每页条数的分页对象
- **参数**: 
  - `page`: int - 当前页码，必须大于0，从1开始
  - `size`: int - 每页条数，必须大于0
- **返回值**: 
  - `Pageable`: 分页对象

#### getPageable(int page, int size, String direction, String properties)
```java
default Pageable getPageable(int page, int size, String direction, String properties)
```
- **功能**: 获取带排序的分页对象（单字段排序）
- **参数**: 
  - `page`: int - 当前页码，必须大于0，从1开始
  - `size`: int - 每页条数，必须大于0
  - `direction`: String - 排序规则，asc/desc
  - `properties`: String - 排序属性，如：userId
- **返回值**: 
  - `Pageable`: 带排序的分页对象

#### getPageableMultiSort(int page, int size, String direction, String properties)
```java
default Pageable getPageableMultiSort(int page, int size, String direction, String properties)
```
- **功能**: 获取带多字段排序的分页对象
- **参数**: 
  - `page`: int - 当前页码，必须大于0，从1开始
  - `size`: int - 每页条数，必须大于0
  - `direction`: String - 排序规则，多个规则用逗号分隔，如：asc,desc
  - `properties`: String - 排序属性，多个属性用逗号分隔，如：userId,createTime
- **返回值**: 
  - `Pageable`: 带多字段排序的分页对象

#### getSpecification(T entity)
```java
default Specification<T> getSpecification(T entity)
```
- **功能**: 根据实体对象生成查询条件（只判断属性值是否相等）
- **参数**: 
  - `entity`: T - 实体对象
- **返回值**: 
  - `Specification<T>`: JPA查询条件对象

#### getSpecification(Map<String, Object> conditions)
```java
default Specification<T> getSpecification(Map<String, Object> conditions)
```
- **功能**: 根据Map条件生成查询条件（只判断属性值是否相等）
- **参数**: 
  - `conditions`: Map<String, Object> - 条件Map
- **返回值**: 
  - `Specification<T>`: JPA查询条件对象

#### getSpecification(Condition condition)
```java
default Specification<T> getSpecification(Condition condition)
```
- **功能**: 根据Condition对象生成查询条件（支持多种查询条件）
- **参数**: 
  - `condition`: Condition - 条件对象，支持等于、不等于、大于、小于、模糊查询、IN、NOT IN等条件
- **返回值**: 
  - `Specification<T>`: JPA查询条件对象

#### updateNotNullField(Object rawObject, Object newObject)
```java
default boolean updateNotNullField(Object rawObject, Object newObject)
```
- **功能**: 根据更新对象的数据更新原始对象（只更新非空字段）
- **参数**: 
  - `rawObject`: Object - 原始对象
  - `newObject`: Object - 更新对象
- **返回值**: 
  - `boolean`: 更新是否成功
- **说明**: 
  - 只更新更新对象中非空的字段
  - 两个对象必须是相同类型
  - 忽略ID字段和创建时间字段

**继承的方法**
从 `JpaRepository` 继承的通用方法：
- 基础的CRUD操作
- 批量操作
- 分页查询
- 排序查询

从 `JpaSpecificationExecutor` 继承的通用方法：
- 条件查询
- 分页条件查询
- 排序条件查询

**使用示例**
```java
@Autowired
private BaseRepository<YourEntity, Long> repository;

// 分页查询
Pageable pageable = repository.getPageable(1, 10, "desc", "createTime");
Page<YourEntity> page = repository.findAll(pageable);

// 条件查询
YourEntity entity = new YourEntity();
entity.setName("test");
Specification<YourEntity> spec = repository.getSpecification(entity);
List<YourEntity> list = repository.findAll(spec);

// 更新非空字段
YourEntity raw = repository.findById(1L).get();
YourEntity update = new YourEntity();
update.setName("new name");
repository.updateNotNullField(raw, update);
repository.save(raw);
```

**继承关系**

  - 泛型参数2: `PK` - 主键类型，必须实现 Serializable 接口

**注解说明**
- `@Transactional`: 标记该接口的所有方法都支持事务
- `@NoRepositoryBean`: 标记该接口不会被 Spring Data JPA 实例化

**接口方法**

#### 统计相关方法
```java
long countActive()
```
- **功能**: 统计所有未删除的记录数
- **返回值**: 
  - `long`: 未删除的记录数

```java
long countActive(Specification<T> conditions)
```
- **功能**: 根据条件统计未删除的记录数
- **参数**: 
  - `conditions`: Specification<T> - 查询条件
- **返回值**: 
  - `long`: 符合条件的未删除记录数

#### 存在性检查方法
```java
boolean existsActive(PK id)
```
- **功能**: 检查指定ID的记录是否存在且未删除
- **参数**: 
  - `id`: PK - 记录ID
- **返回值**: 
  - `boolean`: 如果记录存在且未删除返回true，否则返回false

#### 查询方法
```java
Page<T> findAllActive()
Page<T> findAllActive(Sort sort)
Page<T> findAllActive(Pageable pageable)
```
- **功能**: 查询所有未删除的记录
- **参数**: 
  - `sort`: Sort - 排序条件（可选）
  - `pageable`: Pageable - 分页条件（可选）
- **返回值**: 
  - `Page<T>`: 分页结果

```java
List<T> findAllActiveNoPage()
List<T> findAllActiveNoPage(Sort sort)
```
- **功能**: 查询所有未删除的记录（不分页）
- **参数**: 
  - `sort`: Sort - 排序条件（可选）
- **返回值**: 
  - `List<T>`: 记录列表

```java
List<T> findAllActive(Iterable<PK> ids)
```
- **功能**: 根据ID列表查询未删除的记录
- **参数**: 
  - `ids`: Iterable<PK> - ID列表
- **返回值**: 
  - `List<T>`: 记录列表

```java
List<T> findAllActive(Specification<T> conditions)
Page<T> findAllActive(Specification<T> conditions, Pageable pageable)
List<T> findAllActive(Specification<T> conditions, Sort sort)
```
- **功能**: 根据条件查询未删除的记录
- **参数**: 
  - `conditions`: Specification<T> - 查询条件
  - `pageable`: Pageable - 分页条件（可选）
  - `sort`: Sort - 排序条件（可选）
- **返回值**: 
  - `List<T>` 或 `Page<T>`: 查询结果

```java
T findByIdActive(PK id)
T findOneActive(PK id)
```
- **功能**: 根据ID查询单个未删除的记录
- **参数**: 
  - `id`: PK - 记录ID
- **返回值**: 
  - `T`: 记录对象，如果不存在或已删除则返回null

```java
T findOneActive(Specification<T> conditions)
```
- **功能**: 根据条件查询单个未删除的记录
- **参数**: 
  - `conditions`: Specification<T> - 查询条件
- **返回值**: 
  - `T`: 记录对象，如果不存在或已删除则返回null

#### 逻辑删除方法
```java
@Modifying
void logicDelete(PK id)
@Modifying
void logicDelete(T entity)
@Modifying
void logicDelete(Iterable<? extends T> entities)
@Modifying
void logicDeleteAll()
```
- **功能**: 执行逻辑删除操作
- **参数**: 
  - `id`: PK - 记录ID
  - `entity`: T - 实体对象
  - `entities`: Iterable<? extends T> - 实体对象集合
- **说明**: 
  - 这些方法会更新记录的删除标记，而不是物理删除数据
  - 所有方法都使用 `@Modifying` 注解标记为修改操作

```java
@Modifying
void deleteAllByIds(Iterable<? extends PK> ids)
```
- **功能**: 根据ID列表批量逻辑删除记录
- **参数**: 
  - `ids`: Iterable<? extends PK> - ID列表

#### 定时删除方法
```java
@Modifying
void scheduleLogicDelete(PK id, LocalDateTime localDateTime)
@Modifying
void scheduleLogicDelete(T entity, LocalDateTime localDateTime)
```
- **功能**: 设置定时逻辑删除
- **参数**: 
  - `id`: PK - 记录ID
  - `entity`: T - 实体对象
  - `localDateTime`: LocalDateTime - 计划删除时间
- **说明**: 
  - 这些方法用于设置记录在指定时间后自动逻辑删除

**继承的方法**
从 `SystemRepository` 继承的所有方法：
- 分页查询相关方法
- 条件查询相关方法
- 更新非空字段方法
- 其他基础数据访问方法

**使用示例**
```java
@Repository
public interface YourRepository extends LogicRepository<YourEntity, Long> {
    // 可以添加自定义的查询方法
}

// 使用示例
@Autowired
private YourRepository repository;

// 查询未删除的记录
Page<YourEntity> page = repository.findAllActive(PageRequest.of(0, 10));

// 条件查询
Specification<YourEntity> spec = (root, query, cb) -> 
    cb.equal(root.get("name"), "test");
List<YourEntity> list = repository.findAllActive(spec);

// 逻辑删除
repository.logicDelete(1L);

// 定时删除
repository.scheduleLogicDelete(1L, LocalDateTime.now().plusDays(7));
```
