## GenericController 类文档

### 类描述
通用类对象控制器，提供基础的 CRUD 操作接口，支持分页查询、条件查询等功能。

### 包路径
com.simbest.cloud.cores.base.web.controller

### 主要属性
- service：IGenericService<T, PK> 类型，用于数据访问

### 构造方法
- GenericController(IGenericService<T, PK> service)：注入数据访问层对象

### 方法列表
- **JsonResponse findById(@RequestParam(name = "id") PK id)**
  - 入参：id（主键）
  - 出参：JsonResponse
  - 功能描述：根据主键查询实体

- **JsonResponse findOne(@RequestBody T o)**
  - 入参：o（实体对象，包含查询条件）
  - 出参：JsonResponse
  - 功能描述：根据实体对象查询单个实体

- **JsonResponse findAll(@RequestParam(required = false, defaultValue = "1", name = "page") int page, @RequestParam(required = false, defaultValue = "10", name = "size") int size, @RequestParam(required = false, name = "direction") String direction, @RequestParam(required = false, name = "properties") String properties, @RequestBody T o)**
  - 入参：page（页码），size（每页条数），direction（排序方向），properties（排序属性），o（实体对象，包含查询条件）
  - 出参：JsonResponse
  - 功能描述：分页查询实体列表

- **JsonResponse findAllNoPage(@RequestBody T o)**
  - 入参：o（实体对象，包含查询条件）
  - 出参：JsonResponse
  - 功能描述：不分页查询实体列表

- **JsonResponse findAllSortNoPage(@RequestParam(required = false, name = "direction") String direction, @RequestParam(required = false, name = "properties") String properties, @RequestBody T o)**
  - 入参：direction（排序方向），properties（排序属性），o（实体对象，包含查询条件）
  - 出参：JsonResponse
  - 功能描述：不分页查询实体列表（带排序）

- **JsonResponse create(@RequestBody T o)**
  - 入参：o（待创建实体）
  - 出参：JsonResponse
  - 功能描述：创建实体

- **JsonResponse update(@RequestBody T newObj)**
  - 入参：newObj（待更新实体）
  - 出参：JsonResponse
  - 功能描述：更新实体

- **JsonResponse deleteById(@RequestParam(name = "id") PK id)**
  - 入参：id（主键）
  - 出参：JsonResponse
  - 功能描述：根据主键删除实体

- **JsonResponse delete(@RequestBody T o)**
  - 入参：o（待删除实体）
  - 出参：JsonResponse
  - 功能描述：删除实体

- **JsonResponse deleteAllByIds(@RequestBody PK[] ids)**
  - 入参：ids（主键数组）
  - 出参：JsonResponse
  - 功能描述：批量删除实体

## RedisTestController

### 类描述
分布式锁测试控制器，提供Redis分布式锁的测试接口，用于验证分布式锁的功能。

### 包路径
`com.simbest.cloud.cores.component.distributed.lock`

### 主要属性
- `distributedLockTemplate`: DistributedLockTemplate 类型，分布式锁模板对象

### 方法列表
1. `lock()`
   - 功能：测试基本的分布式锁功能
   - 参数：无
   - 返回值：void
   - 请求路径：/redis/lock
   - 请求方式：POST
   - 功能描述：创建100个线程并发测试分布式锁，每个线程获取锁后休眠10秒

2. `template()`
   - 功能：测试分布式锁模板功能
   - 参数：无
   - 返回值：void
   - 请求路径：/redis/template
   - 请求方式：POST
   - 功能描述：创建100个线程并发测试分布式锁模板，每个线程获取锁后休眠10秒

### 内部类
#### DisplayMessage
- 继承自 Thread 类
- 构造函数：`DisplayMessage(DistributedLockTemplate distributedLockTemplate)`
- 重写方法：
  - `run()`: 执行分布式锁测试逻辑
  - `process()`: 获取锁后的处理逻辑
  - `getLockName()`: 获取锁的名称
